# macOSネイティブアプリ開発ルール

## メニューバーアプリ: NSStatusItem非表示問題（macOS 15+）

macOS 15 (Sequoia) 以降、メニューバーが混雑している場合に `NSStatusItem` が表示されないことがある。`variableLength` は特に隠されやすい。

**Why:** macOS 15はメニューバーの溢れを自動的に処理し、サードパーティのステータスアイテムを非表示にする。ユーザーのメニューバーにアイコンが多い場合、新規アプリのNSStatusItemが一切見えないことがある。

**How to apply:**
- メニューバーアプリを作る際、`NSStatusItem` が表示されない可能性を設計段階で考慮する
- 代替として `NSWindow(level: .statusBar)` のフローティングオーバーレイが確実
- 動作確認時に「アイコンが見えない＝実装が壊れている」と即断しない。まずメニューバーの溢れ設定を疑う

## Ad-hoc署名とTCC権限のリセット

`codesign --force --sign -`（ad-hoc署名）でリビルドするたびに、TCC権限（カメラ・カレンダー等のアクセス許可）がリセットされる。

**How to apply:**
- 開発中に権限まわりの挙動が急におかしくなったら、まずTCCリセットを疑う
- `tccutil reset Calendar <bundleId>` のように対象サービスをリセット → 再度アプリを起動して許可ダイアログから許可し直す
- この現象を「バグ」と誤診断してコードを疑う前に、直前のリビルド（再署名）の有無を確認する
